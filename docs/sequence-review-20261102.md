# 0.1.15 序列动作联合检查

日期：2026-11-02。检查对象是 `src/assets/nailao/sequences/manifest.json` 指定的六个无损动画 WebP，而非旧版网格或另做的演示素材。

## 修复

- 使用原来的完整姿态关键帧；举爪、转头与伸展恢复起始姿态、动作到位和返回过程。
- 对齐静止区域，再锁定不动部分的毛纹。眯眼/眨眼的身体轮廓逐帧一致。
- 离线生成30fps中间姿态；RGBA共用相同流场与遮挡权重，防止颜色和透明轮廓错位。App只播放完整帧，没有运行时帧混合。
- 固定全局比例。伸展只校正源素材头部尺度漂移，保留头部约150px下压；歪头恢复约20°幅度。
- 透明区域清理，保留安全边距。无损WebP保留颜色与半透明毛边，GIF采用统一调色板、关闭抖色并清除上一帧。
