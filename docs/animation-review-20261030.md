## 根因与此前检查缺口

16张独立生成姿态的毛纹、形状不完全一致。光流不能可靠推断被遮挡部位；混合产生双重细节，而遮挡保护在过渡中点切换源姿态，又引入明显突跳。逆向位移迭代还会在部分局部产生折叠/缺口。

此前的帧率、外接面积、安全边距和合成不透明方块测试只覆盖部分性质，漏掉真实猫咪身体内部的几何错误。纹理突跳数据虽被采集，却未作为联合失败条件。

新增 `npm run verify:animation`，将真实动作内部的源帧切换突跳设为失败条件。当前六动作全部失败；不要通过放宽阈值来获得通过结果。检查通过后仍需逐个完整观看真实动作，不能仅靠合成图案或平均帧率验收虚影。

## 后续修复

先试制时间上连贯的动作源素材，确认毛纹一致、关节自然、完整轮廓及循环接缝；六动作使用同一套尺寸、透明边缘、纹理连续性、重影与帧间隔验收，再统一安装与更新导出。不要继续将当前补帧结果宣布为修复完成。
