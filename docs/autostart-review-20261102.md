# 0.1.16 开机自启动

在“设置提醒”页面最下方、保存栏上方增加开关。文案说明登录 Mac 后自动启动，更改立即生效。系统登录项为状态来源，不在提醒设置中另存一个可能失真的布尔值，也不在启动时强制覆盖系统配置。

通过 Electron 官方 [getLoginItemSettings / setLoginItemSettings](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings-macos-windows) 接入。`requires-approval` 显示系统登录项批准提示；注册失败显示错误并读取实际状态。网页预览与未打包开发版禁用开关，避免把开发工具注册为登录项。

验证（2026-11-02）：

- 全部40项测试通过，覆盖系统外部更改、待批准、无效参数、不支持平台、拒绝写入和异常。
- 本机已安装0.1.16，签名与构建检查通过。
- 原生页面检查：新增行在提醒设置底部，样式与现有开关一致。
- 原生实测：关闭→开启，退出并重新打开App后仍开启，再关闭成功；最终恢复原来的关闭状态。
- 设置文件字节与原定下一次提醒时间保持不变；自启动开关没有重置提醒计划。
- 六动作及图标内容不变，包内资源与原版本一致。

没有重启整台Mac或注销用户；已验证系统登录项注册、移除和App重启后的状态回显。实际登录触发由macOS管理。
